# Scooby - Pet Care Website

This is a Pet Care website built using React and Vite. 

The website includes different sections like a nav-bar, hero section, services, about, testimonials, team, blog, contact section, and footer.

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML
- CSS
- Swiper.js

## Features

- Responsive Navbar
- Hero section with image slider
- Services section with slider
- About section
- Why Choose Us section
- Working process section
- Testimonials
- Team section
- Blog section
- Contact section
- Responsive design
